# ⚙️ 守护进程管理

## 操作速查

| 操作 | 命令 |
|------|------|
| start | `bash scripts/daemon.sh start` |
| stop | `bash scripts/daemon.sh stop` |
| restart | `bash scripts/daemon.sh restart` |
| status | `bash scripts/daemon.sh status` |
| cron | `crontab -l \| grep daemon` |
| diagnose | 见下方 |

## diagnose 诊断清单

1. `ps aux | grep -E "reminder_daemon\|annual_scheduler"` — 是否多实例
2. `cat scripts/*.pid` 与进程 PID 比对 — PID 文件是否有效
3. `crontab -l | grep daemon` — 是否有 `@reboot` + `*/5 * * * *`
4. `grep -E "错误\|失败" scripts/*.log | tail -20` — 近期错误

> 异常排查时读 `.codebuddy/skills/helper-scripts-spec/references/06-daemon.md`，不要调用 `use_skill`。
