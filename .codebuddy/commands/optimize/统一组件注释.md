# 🛠 统一组件注释

把 `web/frontend/src/components/**/*.vue` 全部子组件文件的 `defineProps` / `defineEmits` / `defineModel` JSDoc 注释统一成 [webhook-form.vue](web/frontend/src/components/config/webhook-form.vue) 风格。

> 与 `/统一Model注释` `/统一Service注释` 配套：本指令**只动注释**，不改业务逻辑、不改组件模板、不改方法体。
>
> ⚠️ 跳过 `views/` 下的页面组件（页面级 props/emits 极少且通常被 router 注入）；跳过 `__experiments__/` 实验目录。

| 4️⃣ | 对每个文件按规则补注释：内联泛型 → 字段上方加 `/** */` / `interface Props` → interface 字段上方加 / Options 对象式 → prop 名上方加 / `defineModel` 上方加固定语法糖模板 / `rule-card.vue` 数组式 → 升级为元组并逐条加注释 | ✅ |

## 🎯 关键规则（速查）

| 目标 | 模板 |
|------|------|
| **格式** | 单行 JSDoc `/** 中文描述 */` 独占一行，紧贴字段；禁止同行尾注释 / 多行 JSDoc / 行内 `//` |
| **写法 A 内联** | `defineProps<{ /** xxx */ field: T }>()` —— 注释贴**内联字段**上方 |
| **写法 B withDefaults 内联** | 同 A，注释贴内联字段；`withDefaults` 第二参原样保留 |
| **写法 C 外部 interface Props** | 注释贴 `interface Props` **字段上方**（不是 `defineProps<Props>()` 调用上方） |
| **写法 D Options 对象式** | 注释贴 **prop 名**上方（`/** */` + `loading: { type: Boolean }`），不贴 `type:` 内层 |
| **emits 长签名** | `/** xxx */` 贴 `(e: 'xxx'): void;` 上方 |
| **emits 短元组** | `/** xxx */` 贴 `xxx: [...];` 上方 |
| **emits 数组式** | **必须升级为元组** 后逐条注释（`rule-card.vue` 唯一一处） |
| **defineModel 默认** | `/** XXX（v-model，Vue 3.4+ defineModel 语法糖） */` |
| **defineModel 命名** | `/** XXX（v-model:<name>，Vue 3.4+ defineModel 语法糖） */` |

### ✅ 必须执行
- 改完跑 `rg -c "defineModel" web/frontend/src/components/ -g "*.vue"` 与 `rg -c "Vue 3.4\+ defineModel 语法糖" web/frontend/src/components/ -g "*.vue"`，**两个数字应一致**
- 改完跑 `rg "defineEmits\(\[" web/frontend/src/components/ -g "*.vue"`，**结果必须为空**（数组式 emits 残留）
- 每次 `multi_replace` 后立刻 `read_lints` 确认 import 未变 unused
- 保留原有写法：长/短 emits 不强制改、Options 对象式不强制升级泛型、`withDefaults` 第二参对象一字不动
- 写法 B `withDefaults(defineProps<{...}>(), {...})` 替换时 `old_string` 必须包含到末尾 `});`，避免漏掉默认值

### ❌ 严格禁止
- 把所有写法的注释都贴到 `defineProps()` 调用上方（hover 不到，违反规则 1）
- 给 `interface Props` 字段加多行 `/**\n * xxx\n */` 形式（应单行）
- 修改 `withDefaults` 的默认值对象、修改 props 字段类型、修改 emits 事件名
- 顺手把 Options 对象式升级为泛型（属于结构性重构，应单独走 `/优化Web架构`）
- 把 `<template>` / `<style>` / 业务逻辑 `<script setup>` 主体一起替换
