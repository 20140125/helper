# 🖼️ 生成信息卡片

将用户自然语言关键字映射为 `scripts/tools/` 下的卡片脚本，执行后产出 PNG 并通过 `MEDIA:` 指令下发。

## 📋 执行流程

| 步骤 | 操作 | 说明 | 必须 |
|-----|------|------|-----|
| 1️⃣ | **提取关键字** | 从用户输入 `$1` 中抽出主体（平台 + 类型 / 场景词） | ✅ |
| 2️⃣ | **总路由执行** | 运行 `bash scripts/tools/card.sh "<关键字>"` 让 `card.sh` 内部查表路由 | ✅ |
| 3️⃣ | **取 PNG 路径** | 读取子脚本 stdout 输出的 PNG 绝对路径 | ✅ |
| 4️⃣ | **下发图片** | 输出 `MEDIA: /path/to/xxx_card.png` 指令 | ✅ |

### 详细说明

#### 1️⃣ 提取关键字

用户可能给出的形式：

- 直接关键字：`B 站剧集` / `腾讯动漫` / `今日油价`
- 完整句子：`看看 A 股大盘` / `来一张 GitHub 榜`
- 含糊指令：`推一条行情` → 需回问具体类别

**你要做的**：抽取核心词作为 `<关键字>` 传给 `card.sh`。不确定时优先问用户，禁止猜测。

#### 2️⃣ 总路由执行（**首选路径**）

```bash
bash scripts/tools/card.sh "<关键字>"
```

- 成功：stdout 单行 PNG 绝对路径，退出码 `0`
- 关键字未命中：stderr 提示 `FAILED: 未识别的关键字`，退出码 `2`
- 不知道传什么时，先跑 `bash scripts/tools/card.sh --list` 看全量关键字

#### 3️⃣ 关键字未命中时的 fallback

只有当 `card.sh` 返回退出码 2 时才走人工路由：

1. 读取 `.codebuddy/skills/info-cards/SKILL.md` 的「关键字 → 脚本路由」章节
2. 按影视综艺的 `<平台> + <类型>` 二维组合手动映射
3. 若仍无法确定，反问用户，**不要执行任意一个脚本碰运气**

#### 4️⃣ 下发图片

```
MEDIA: /projects/helper/web/public/skill-images/xxx_card.png
```

绝对路径来自 `card.sh` 的 stdout，不要自己拼路径。

## 🎯 关键规则

### ✅ 必须执行
- **默认走 `card.sh`**：一律先用 `bash scripts/tools/card.sh "<关键字>"` 路由，比手读 SKILL.md 更确定、更快。
- **路径来源唯一**：PNG 路径只取子脚本 stdout 首行，不要自己拼 `web/public/skill-images/...`。
- **不命中时反问**：关键字未命中且 fallback 也定位不到时，列出候选关键字给用户选，**禁止随机挑一个脚本跑**。

### ❌ 严格禁止
- 跳过 `card.sh` 直接 `bash scripts/tools/xxx.sh`——除非用户**明确点名**某个脚本。
- 手工猜测脚本名（如凭感觉写 `bilibili_tv.sh`，实际是 `hot_tv.sh`）。
- 对 `card.sh` 的 stderr 输出走 `MEDIA:` 下发——失败分支不出图。
- 为 fallback 去改 `SKILL.md` 或 `card.sh` 的关键字表——那属于 `/优化脚本结构` 或人工维护的职责，不在本指令范围。
