# 🧬 生成 TypeScript 类型

通过 `generate-type.ts` 工具，一键生成符合规范的类型脚手架——产出物**自带**：`Item`（实体接口）、`QueryParams`（列表查询入参）、`FormData`（表单数据）、`ListResponse`/`DetailResponse`（带 `code: number` 的统一响应壳）。

> 🎯 适用场景：新接口接入第 1 步，或新模块从零拉起类型层。手写易漏 `code` 字段、易忘 `?` 标记可选属性，用此命令产出物再做业务即可。
>
> 🚦 **何时不用本命令**：仅给已有类型补 1~2 个字段时，直接编辑 `web/frontend/src/types/<模块>.ts` 更快——本命令是"从零起骨架"工具，不会在已有文件上 patch。

## 📋 执行流程

| 步骤 | 操作 | 必须 |
|-----|------|-----|
| 1️⃣ | 确认模块名（kebab-case，例：`user` / `webhook` / `api-token`） | ✅ |
| 2️⃣ | 在 `web/` 目录执行 `npm run gen:type -- <args>`（或 ts-node 直跑） | ✅ |
| 3️⃣ | 工具产出文件后，**根据后端契约**填充 `Item` 实际字段、修正 `string` 占位 | ✅ |
| 4️⃣ | 同步 `services/<模块>-service.ts` 引用 `import type { ... } from '@/types/<模块>'` | ✅ |
| 5️⃣ | 跑 `/审查Web规范` 确认产出物合规 | 推荐 |

## 🚀 标准调用

```bash
cd web

# 全量生成（Item + QueryParams + FormData + ListResponse + DetailResponse）
npm run gen:type -- user

# 只要实体 + 表单（不要列表查询/响应壳）
npm run gen:type -- product --no-list --no-response

# 只要实体（最小骨架）
npm run gen:type -- system-config --no-list --no-form --no-response
```

ts-node 直跑（脱离 web/ 目录）：
```bash
npx ts-node -P .codebuddy/skills/helper-web-spec/scripts/tsconfig.json \
  .codebuddy/skills/helper-web-spec/scripts/generate-type.ts <模块名> [--no-list] [--no-form] [--no-response]
```

## 📁 产出位置

| 产物 | 路径 |
|------|------|
| 类型文件 | `web/frontend/src/types/<模块>.ts` |

## ⚠️ 后处理（工具产出后必做）

1. 把 `Item` 中的 `string` / `number` 占位字段替换为**后端契约里的真实字段**（含 `?` 可选标记）
2. `ListResponse` 必须保留 `code: number` 与 `data: { list: Item[]; total: number }` 的统一响应壳形状（Service 层 `BaseService` 依赖此结构）
3. 同步在 [services/](/projects/helper/web/frontend/src/services) 下相同模块名的 service 文件中 `import type` 引入
4. 不要直接把工具产出物提交，**至少做一次"业务字段填充"再 commit**

## ❌ 禁止
- 文件已存在时强制覆盖（工具会报错退出，先决定是否手动归档旧文件）
- 把 `gen:type` 产出物当作"完成态"——它是**起点不是终点**
- 把模块名传成 PascalCase（应使用 kebab-case，如 `api-token` 不是 `ApiToken`）
- 在 `types/<模块>.ts` 里写函数 / 写 `export const`——按规范这里**只放类型**，常量去 `constants/`，函数去 `utils/`

## 🔄 工具失败时的兜底

若 `npm run gen:type` 失败：
1. 读 `.codebuddy/skills/helper-web-spec/references/12-scripts-cli-reference.md` 重新核对参数
2. 若仍不可用，**回退到手写**——读 `references/03-service-and-types.md`，按规范手写脚手架
