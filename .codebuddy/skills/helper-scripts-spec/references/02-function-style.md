# 2. 函数定义与分割线规范

---

## 函数注释与变量

```bash
# 函数功能简述
# 参数：
#   $1 - 参数名称（类型说明）
#   $2 - 参数名称（可选，默认值说明）
# 返回：成功 0 | 失败 1
函数名() {
    local param1="$1"
    local param2="${2:-默认值}"
    # 函数体
}
```

- 内部变量用 `local` 声明——避免污染全局作用域
- 参数赋值用具名变量——比裸 `$1`、`$2` 可读性好
- 有默认值用 `${参数:-默认值}`

## 主入口模式

**主脚本**（直接被 cron 或用户调用）：

```bash
main() {
    log_info "======================================"
    log_info "🚀 脚本名称启动"
    log_info "📅 当前时间: $(date '+%Y-%m-%d %H:%M:%S')"
    log_info "======================================"

    # 主逻辑...

    log_success "脚本执行完成"
    log_info "======================================"
}

main "$@"
```

**子工具脚本**（可被 `source` 引入，也可直接执行）：

```bash
main() {
    if [ $# -lt 2 ]; then
        log_error "用法: $0 <年份> <JSON文件路径>"
        exit 1
    fi
    local year="$1"
    local json_file="$2"

    log_info "======================================"
    log_info "🚀 子工具脚本名称启动"
    log_info "📅 当前时间: $(date '+%Y-%m-%d %H:%M:%S')"
    log_info "📦 处理年份: ${year}"
    log_info "======================================"

    if 业务函数 "$year" "$json_file"; then
        log_success "脚本执行完成"
    else
        log_error "执行失败"
    fi
    log_info "======================================"
}

# Guard：仅直接执行时调用 main
if [ "${BASH_SOURCE[0]}" = "$0" ]; then
    main "$@"
fi
```

## 启动/结束日志

所有脚本统一格式：

- **启动**：分割线 → `🚀 脚本名启动` → `📅 时间` → 分割线
- **成功**：`log_success "脚本执行完成"` + 分割线
- **失败**：`log_error "具体原因"` + 分割线 + `exit 1`
