# 企微推送

## 什么时候用

用户要求**把内容发到群里**。只是"看一下 / 有没有"类查询不推送，改用查询工具或 `card_skill`。

## 立即推送 vs 定时规则（最容易出错）

| 用户说法 | 该做什么 |
|---------|---------|
| "把刚才查到的发到群里" | `send_wecom_message` 立即推 |
| "每天 15:00 推 A 股到群里" | **只能** `create_rule` 建定时规则，守护进程到点推 |
| "每周一 9 点提醒大家写周报" | 同上，建规则 |

**定时语义一律建规则，禁止用 `send_wecom_message` 补发一条**——否则用户在设定时间之前就收到了。
建完规则后也不要再调本工具"验证一下"。

## 调用要求

- `content`：必须来自上游工具返回或用户原文，**禁止自造**（没有查过就说没数据，不编内容）
- `user_consent_phrase`：从用户原话摘录能体现推送意图的短语，**禁止编造**
- 严格模式下本工具属"动作"而非数据变更：需 consent，但正常执行、不自动建审批单；
  用户说「先别发 / 等我确认 / 走审批」时用 `request_approval` 挂起

## 排版

企微机器人只支持 **标题 / 加粗 / 列表 / 引用**，不支持表格。多条数据用列表，不要用 `|` 表格语法，
也不要贴原始 JSON。

## 反馈

推送完成后告知推了什么、推到哪个群（机器人名称）；失败如实说明原因，不要说"已推送"。
